## 1 funckey 和 alias 的区别

`alias` 和 `funckey` 都能把 Allegro 命令绑定到快捷键。主要区别是：**使用字母或数字时，是否需要按 Enter 执行。**

| 对比项 | `alias` | `funckey` |
| --- | --- | --- |
| 主要用途 | 定义命令缩写，也可以绑定功能键 | 定义在绘图区直接触发的快捷键 |
| 字母／数字 | 输入缩写后按 `Enter` 执行 | 焦点在绘图区时，按下对应键即可执行 |
| F1、F2、F3 等功能键 | 按键即可执行，无需 `Enter` | 对这些功能键，触发效果基本相同 |
| 多字母缩写 | 适合输入完整缩写后确认执行 | 支持最多 4 个字母／数字；输入匹配后直接触发 |
| 焦点在命令输入框时 | 作为命令输入，按 `Enter` 执行 | 也按命令输入方式处理，不按绘图区直接触发 |

例如，以下是两种不同的绑定方式，选择一种即可，不要同时给 `z` 重复定义：

```text
alias z "zoom fit"
```

输入 `z` 后按 `Enter`，缩放以完整显示当前设计。

```text
funckey z "zoom fit"
```

焦点在绘图区时，直接按 `Z` 就执行，无需 `Enter`。

### 1.1 什么时候使用 funckey

希望在绘图区直接按字母或数字执行常用操作时，使用 `funckey`，例如缩放、显示设置，或在命令中调整支持的选项。

```text
funckey z "zoom fit"
funckey r "iangle 90"
```

- `z`：在绘图区直接执行缩放。
- `r`：在支持交互旋转的操作中，例如手工放置器件且器件跟随鼠标时，按键旋转 90°；它不是任何状态下都能旋转对象的通用命令。

多字母 `funckey` 要避免前缀冲突。例如同时定义 `a` 和 `ac`，输入第一个 `a` 就可能已经触发，后面的 `ac` 无法正常使用。

### 1.2 什么时候使用 alias

希望输入一个容易记忆的命令缩写，再按 Enter 确认时，使用 `alias`；绑定 `F1～F12` 等功能键时，也可以直接使用 `alias`。

```text
alias ac "add connect"
alias F3 "add connect"
alias F2 done
```

- `ac`：输入 `ac`，按 `Enter`，进入 **Route → Connect** 布线命令。
- `F3`：直接按 `F3` 进入布线，无需 `Enter`。
- `F2`：直接按 `F2` 执行 `done`，结束当前支持该命令的操作。

因此，**`alias` 并不是都要按 Enter，`funckey` 也不只用于 F1、F2 这类功能键。** 字母快捷键需要直接触发时选 `funckey`；命令缩写和功能键绑定可以用 `alias`。

是否打断当前布线、能否在命令进行中执行，取决于绑定的具体命令，不能只根据 `funckey` 或 `alias` 判断。

### 1.3 定义位置与保存

可以先在 Allegro 命令窗口输入定义并按 `Enter`，对当前会话生效。要在下次启动时继续使用，需要把定义写入个人环境目录 `pcbenv` 下的 `env` 文件，再重新启动 Allegro。

## 2 快捷键

以下为当前使用的快捷键配置。字母 `funckey` 在绘图区有焦点时直接按键执行；命令是否可用仍取决于当前操作状态。第一部分中的绑定仅为语法示例，实际配置以本表为准。

| 按键 | 功能与使用说明 |
|---|---|
| `w` | 交互布线，选择焊盘、过孔或已有走线开始连接 |
| `a` | 滑移调整走线、过孔等对象，常用于修线 |
| `k` | 给对象或网络指定显示颜色 |
| `e` | 查看对象信息，如 Class、Subclass、网络、坐标等 |
| `r` | 显示指定网络的飞线 |
| `u` | 隐藏指定网络的飞线，与 `r` 配对使用 |
| `m` | 镜像所选对象；Standard Mirror 可将器件翻到另一面，具体行为看镜像选项。交互放置中的右键 Mirror 对应 `pop mirror`，与此命令不同 |
| `b` | 修改对象参数，例如走线宽度、文字 Text Block；具体可改项看 Options |
| `c` | 复制对象 |
| `d` | 取消对象或网络的高亮；不会清除 Assign Color 指定的颜色 |
| `h` | 高亮对象或网络，便于定位和跟踪连接 |
| `q` | 移动器件、文字等对象 |
| `t` | 打开 Status，查看未布线、铺铜更新及 DRC 等状态 |
| `g` | 执行当前命令的 Next，含义取决于操作，例如继续下一项或下一对象 |
| `s` | 交换器件位置；预选方式下选择两个器件后执行 |
| `i` | 放大视图 |
| `o` | 缩小视图 |
| 空格 | 在支持交互旋转的命令中旋转 90°，例如移动器件且器件跟随鼠标时 |
| Ctrl＋空格 | 在支持交互旋转的命令中旋转 45°；`~` 表示 Ctrl |
| Esc | 执行 Done，完成／结束当前操作；不同于取消本次修改的 Cancel |
| Delete | 进入删除命令，删除所选或随后选取的对象 |
| F2 | 绘制闭合多边形 Shape；在 Options 中选择层、填充类型和网络，可用于铺铜等 |
| F3 | 选择 Shape／Void 并编辑边界或参数 |
| F4 | 测量距离、间距等；本配置会把 F4 重新绑定为测量 |

**空格旋转注意：**要先进入 Move、手工放置等支持旋转的操作，并让器件处于可旋转状态。若提示 `angle command is not allowed in this mode`，说明当前模式不接受角度输入。`~` 的 Ctrl 修饰符用法可参考 [Cadence 快捷键说明](https://community.cadence.com/cadence_technology_forums/pcb-design/f/pcb-design/19217/keyboard-hotkeys)。

修改后可在命令窗口输入 `alias` 或 `funckey` 查看当前实际生效的绑定；长期使用时将配置保存到个人 `pcbenv/env` 文件。
